## 4 · AI chalu karna (sirf website se)

1. **Free key banao** — [aistudio.google.com](https://aistudio.google.com/apikey) → *Get API key* → copy.
   (Groq ka `gsk_…` ya OpenAI ka `sk-…` bhi chalega — provider key ke prefix se khud pehchana jata hai.)
2. HQ kholo → **Social → AI SEO Studio** → upar **Connect AI** (ya Multi-Channel Studio → Connect AI).
3. Key paste karo → **Test** (server asli call karke check karta hai) → **Save & use**.
4. Ab **Generate** asli model output deta hai, aur pack ke upar likha hota hai
   *"Written by Google Gemini · gemini-2.5-flash"*.

Key kahan jati hai: browser me **save nahi hoti**. Server usay `HQ_TOKEN_KEY` se
AES-GCM encrypt karke `hq_ai_keys` table me rakhta hai — us table par RLS on hai aur
koi policy nahi, sirf service role (server function) parh sakta hai. UI ko sirf hint
milta hai: `AIza…1f2e`.

Key hataani ho? Wahi modal → **Remove saved key**.

> Agar aap ne Cloudflare me `AI_API_KEY` rakhi hui hai to wo pehle try hoti hai
> (dashboard jeet jata hai). Tab bhi sab kuch waise hi chalta rehta hai.

## 6 · Media tab me ab kya naya hai

* **Progress + honest result** — "Uploading 2 of 5…", phir "3 uploaded, 2 failed — <wajah>".
  Fail hui file ki wajah naam ke saath aati hai (size / type / session / network).
* **Kuch bhi fail ho to** red banner + **Retry** — khaali library jaisa dikhawa nahi.
* **Recover from bucket** — `site-media` me jo files hain magar `media` table me row
  nahi (purane uploads, classic CMS ke uploads), unhein wapas library me le aata hai.
  Pehle confirm poochta hai, phir ek ek row add karta hai.
* **Preview modal** — video controls ke saath, folder assign, storage path, MIME, URL.
* **Broken preview** — agar stored object gayab ho to "preview missing" chip,
  page crash nahi.
* Delete ab asli me row + storage object dono hataata hai (pehle kuch nahi hota tha).
